# Proposte grafiche (anteprime, non applicate al sito)

Tre direzioni alternative applicate alla home reale come foglio di stile aggiuntivo.
Nessun file del sito è stato modificato: ogni anteprima è una copia di `index.html` che carica anche `proposte/<nome>.css`.

- `a-luce-del-giorno` — tema chiaro editoriale (palette "carta" dell'area riservata), hero diviso testo/immagine.
- `b-matrice-led` — scuro tecnico, titoli in Jost maiuscolo, ciano come accento forte, trama LED visibile.
- `c-grafite` — fondi grafite caldi, forme arrotondate, eventi in fascia scorrevole, servizi a card.

Vedere: `python3 -m http.server 8000` → http://localhost:8000/proposte/a-luce-del-giorno/ (e le altre).
